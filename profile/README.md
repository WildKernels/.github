# WildKernels

Welcome to WildKernels — Building kernels and more for Android.

## Disclaimer

**Your warranty is no longer valid!**

We are not responsible for bricked devices, damaged hardware, or any issues that arise from using these kernels.

Please do thorough research and fully understand the features included before flashing.

By flashing these kernels, **YOU** are choosing to make these modifications. If something goes wrong, do not blame us.

## Repositories

- [GKI_KernelSU_SUSFS](https://github.com/WildKernels/GKI_KernelSU_SUSFS) — Generic GKI kernels
- [Sultan_KernelSU_SUSFS](https://github.com/WildKernels/Sultan_KernelSU_SUSFS) — Pixel kernels
- [Samsung_KernelSU_SUSFS](https://github.com/WildKernels/Samsung_KernelSU_SUSFS) — Samsung kernels
- [OnePlus_KernelSU_SUSFS](https://github.com/WildKernels/OnePlus_KernelSU_SUSFS) — OnePlus kernels
- [kernel_patches](https://github.com/WildKernels/kernel_patches) — Shared kernel patches

## Development Tools & Resources

- [Kernel Patches](https://github.com/WildKernels/kernel_patches)
